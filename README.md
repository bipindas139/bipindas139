# Bipindas K V

Embedded firmware developer in Bengaluru. I write bare-metal C for ARM microcontrollers and systems-level C on Linux.

On the firmware side I work on the LPC2129 (ARM7TDMI-S) in Keil, writing UART, SPI, I2C, ADC and timer drivers directly against the peripheral registers, with interrupt-driven code on top. On the Linux side I write C programs using processes, threads, IPC, System V semaphores and file I/O. Before that I spent a year as a network engineer on Ericsson telecom site integration at MasTec QuadGen.

## Projects

- **LPC2129 drivers:** SPI interfacing with the 25AA1024 EEPROM and MCP3204 ADC; I2C RTC.
- [IoT Patient Health Monitoring System](https://github.com/bipindas139/lpc2129-iot-health-monitor-system): LPC2129 reads a MAX30102 and DHT11 and sends the data to ThingSpeak through an ESP8266.
- [Dining Philosophers](https://github.com/bipindas139/system-v-semaphore-dining-philosophers): process synchronization on Linux using System V semaphores.
- [Student Record CLI](https://github.com/bipindas139/cli-student-record-system): C, linked lists, dynamic memory allocation and file handling.
- [Pothole Detection and Filling System](https://github.com/bipindas139/pothole-detection-system): Arduino Nano with ultrasonic sensors, YOLOv8 and OpenCV detection, Firebase.
